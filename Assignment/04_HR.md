# M6 - HR Resource Allocation Assignment

## Objective
Assign human resources to project tasks based on résumé data, work breakdown
structure (WBS) details, and schedule constraints. You will ensure optimal skill matching,
prevent resource over-allocation, build training/hiring plans for skill gaps, and log
resource risks.

## Deliverables & Requirements
Task Allocation: Match available personnel (from the provided résumés) to tasks
identified in your previous assignment's WBS, task details, and network diagram.

## Schedule & Capacity Management: Define specific start and end dates for each resource
assignment to ensure no individual exceeds standard capacity (40 hours/week) or is
double-booked across overlapping tasks.

## Core Automated Processes: 
Your solution must execute the following workflow
functions:
• Staffing Match: Map WBS tasks to specific team members based on skills, role fit,
and availability constraints.
• Training & Gap Analysis: Flag partial skill matches and generate a pre-project
training plan. Flag unresolvable skill gaps as open positions to hire.
• Risk Logging: Identify single-point-of-failure resources and document them in a
Project_Risk_Register.
• Data Output: Commit the finalized task-to-employee mapping, weekly workload,
match status, and training/hiring recommendations to a
Project_HR_Assignments table.

## Implementation Options
Choose one of the following technical pathways to complete the assignment:
Option 1: Docker + n8n Workflow
Approach A (Cloud LLM): Build an automated Retrieval-Augmented Generation (RAG)
pipeline in n8n connecting to the Groq API.
Approach B (Local LLM): Build the n8n pipeline using a local open-source model (e.g.,
Llama 3.2, Mistral, or Qwen 2.5) hosted via Ollama or LocalAI inside Docker.
Option 2: Microsoft Power Automate
Build a flow using available Power Automate actions. (Note: An MS Forms or Power Apps
front-end is optional; you may use a manual trigger with embedded WBS and résumé
data).
Option 3: Interactive LLM / Notebook
Use an LLM interface (e.g., Google Gemini Gems/Notebooks) loaded with the candidate
résumés as source material. Tip: Draft and refine your system prompts using an LLM
before running the final allocation.
